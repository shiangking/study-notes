2. Functions of several variables

2.1 Inputs, outputs and graphs

A function of two variables

$\displaystyle f:D\subseteq\mathbb R^2\to\mathbb R,\qquad (x,y)\mapsto f(x,y)$

takes a point $(x,y)$ as input and returns one scalar. Its graph is the surface

$\displaystyle z=f(x,y)$

in $\mathbb R^3$. A function $f(x,y,z)$ has a three-dimensional input domain, but its graph would require four dimensions; instead, we usually visualise its domain, slices and level surfaces.

Supplementary intuition: freeze variables

Fixing $y=y_0$ turns $f(x,y)$ into the one-variable function $x\mapsto f(x,y_0)$. Fixing $x=x_0$ gives $y\mapsto f(x_0,y)$. These vertical slices let us reuse one-variable ideas such as tangent slopes and limits.

2.2 Evaluating a multivariable function

  1. State the input point clearly.
  2. Substitute every coordinate at the same time, using brackets around negatives and fractions.
  3. Check whether the denominator, logarithm or root is defined.
  4. Simplify only after the restrictions are safe.

Q06.1 worked example

For

$\displaystyle f(x,y,z)=\frac{x-y}{y^2+z^2},$

the denominator is zero exactly when $y=0$ and $z=0$. Thus the domain excludes the entire $x$-axis.

At $(3,-1,2)$:

$\displaystyle f(3,-1,2)=\frac{3-(-1)}{(-1)^2+2^2}=\frac45.$

At $(0,-\frac13,0)$:

$\displaystyle f\!\left(0,-\frac13,0\right)=\frac{0-(-1/3)}{(-1/3)^2+0^2}=3.$

Verification: both denominators are positive, so both inputs are inside the domain.

3. Maximal domains

The maximal domain is the largest set of inputs for which every operation in the formula makes sense as a real number.

ExpressionRequired condition
$1/g(x,y)$$g(x,y)\ne0$
$\sqrt{g(x,y)}$$g(x,y)\ge0$
$1/\sqrt{g(x,y)}$$g(x,y)>0$
$\ln(g(x,y))$$g(x,y)>0$
$1/\ln(g(x,y))$$g(x,y)>0$ and $g(x,y)\ne1$
$\arcsin(g(x,y))$ or $\arccos(g(x,y))$$-1\le g(x,y)\le1$

3.1 Systematic procedure

  1. Work from the innermost operation outward.
  2. Write every restriction separately.
  3. Intersect the restrictions using “and,” not “or.”
  4. Translate expressions such as $x^2+y^2$ into radial geometry.
  5. Draw excluded boundaries dashed and included boundaries solid.

Q06.2 worked example: a logarithm in a denominator

Consider

$\displaystyle f(x,y)=\frac1{\ln(9-x^2-y^2)}.$

Restriction 1 - logarithm:

$\displaystyle 9-x^2-y^2>0\iff x^2+y^2<9.$

This is the inside of the circle of radius $3$, excluding its boundary.

Restriction 2 - denominator:

$\displaystyle \ln(9-x^2-y^2)\ne0.$

Since $\ln u=0$ exactly when $u=1$:

$\displaystyle 9-x^2-y^2\ne1\iff x^2+y^2\ne8.$

Therefore the maximal domain is

$\displaystyle \boxed{D=\{(x,y):x^2+y^2<9,\ x^2+y^2\ne8\}}.$

Sketch: shade the open disk $r<3$, but remove the entire dashed circle $r=2\sqrt2$. Both the inner disk $r<2\sqrt2$ and the annular region $2\sqrt2<r<3$ are included.

Common trap

The logarithm is allowed to be negative. We require its argument to be positive, not the logarithm itself. The extra condition $\ln(\cdot)\ne0$ comes only because the logarithm is in the denominator.

4. Graphs, level curves and level surfaces

The graph $z=f(x,y)$ is a surface. A level curve

$\displaystyle f(x,y)=k$

is the intersection of that graph with the horizontal plane $z=k$, viewed in the $xy$-plane. This is the same idea used by contour lines on a topographical map. For $f:\mathbb R^3\to\mathbb R$, the equation $f(x,y,z)=k$ usually gives a level surface.

Course interpretation: what contours tell you

Moving across contours toward larger labels increases $f$. Closely spaced contours indicate that the output changes rapidly in the crossing direction; widely spaced contours indicate slower change.

4.1 Q06.3: rational-function level curves

For

$\displaystyle f(x,y)=\frac{x+y}{x-y},\qquad x\ne y,$

set $f(x,y)=k$:

$\displaystyle x+y=k(x-y)\iff (1-k)x+(1+k)y=0.$

For $k\ne-1$, solve for $y$:

$\displaystyle y=\frac{k-1}{k+1}x.$
LevelCurveGeometric description
$k=-2$$y=3x$Line of slope $3$
$k=0$$y=-x$Line of slope $-1$
$k=1$$y=0$The $x$-axis
$k=2$$y=x/3$Line of slope $1/3$

Every listed line passes through the origin algebraically, but $(0,0)$ must be removed because the original denominator $x-y$ is zero there. More generally, simplifying a level equation never restores points excluded from the original domain.

4.2 Q06.4: level surfaces

For

$\displaystyle f(x,y,z)=\sqrt{16-x^2-y^2-z^2},$

the domain is the closed ball

$\displaystyle x^2+y^2+z^2\le16.$

Set $f=k$. Because a square root is nonnegative, $k\ge0$. Squaring gives

$\displaystyle x^2+y^2+z^2=16-k^2.$
Value of $k$Level set
$0\le k<4$Sphere centred at the origin with radius $\sqrt{16-k^2}$
$k=4$The single point $(0,0,0)$
$k<0$ or $k>4$Empty set

As $k$ increases from $0$ to $4$, the spheres shrink from radius $4$ to a single point.

5. Limits in several variables

The statement

$\displaystyle \lim_{(x,y)\to(a,b)}f(x,y)=L$

means that $f(x,y)$ approaches the same number $L$ no matter how $(x,y)$ approaches $(a,b)$. Unlike a one-variable limit, there are infinitely many possible paths.

5.1 Method-selection ladder

  1. Direct substitution: use it when the expression is continuous at the target.
  2. Algebraic repair: factor or rationalise if substitution produces $0/0$.
  3. Repeated-expression substitution: set $u=g(x,y)$ when the whole formula depends on one combination such as $2x-y$.
  4. Path comparison: two different path limits prove non-existence.
  5. Squeeze or polar coordinates: use a bound depending only on distance to prove existence when direct methods fail.

Q06.5(i): continuity and direct substitution

$\displaystyle \lim_{(x,y)\to(0,\pi/4)}\sec x\tan(x+y)$

$\sec x$ is continuous where $\cos x\ne0$, and $\tan(x+y)$ is continuous where $\cos(x+y)\ne0$. Both conditions hold at the target, so substitute directly:

$\displaystyle \sec0\tan(\pi/4)=1.$

Q06.5(ii): two equivalent methods

$\displaystyle \lim_{(x,y)\to(2,0)}\frac{\sqrt{2x-y}-2}{2x-y-4}$

Direct substitution gives $0/0$, so simplification is required.

Method A - rationalise:

$\displaystyle \frac{\sqrt{2x-y}-2}{2x-y-4}\cdot\frac{\sqrt{2x-y}+2}{\sqrt{2x-y}+2}=\frac1{\sqrt{2x-y}+2}$

for points near but not equal to the target. The simplified expression is continuous there, so the limit is

$\displaystyle \boxed{\frac14}.$

Method B - reduce to one variable: set $u=2x-y$. Then $(x,y)\to(2,0)$ implies $u\to4$, and the problem becomes

$\displaystyle \lim_{u\to4}\frac{\sqrt u-2}{u-4},$

which is rationalised in exactly the same way. This method exposes that the original expression depends only on $2x-y$.

Q06.6: proving that a limit does not exist

$\displaystyle \lim_{(x,y)\to(0,0)}\frac{y}{x^2}$

Along $y=0$ with $x\ne0$:

$\displaystyle \frac{y}{x^2}=0.$

Along $y=x^2$:

$\displaystyle \frac{y}{x^2}=1.$

The two path limits differ, so

$\displaystyle \boxed{\text{the limit does not exist}.}$

Stronger alternative: along the family $y=cx^2$, the expression equals $c$. It can approach any chosen constant, making the path dependence unmistakable.

What path checking can and cannot do

Two different path answers are enough to disprove a limit. Ten matching paths still do not prove existence because untested paths remain. An existence proof must control every approach, usually through continuity, an inequality, the squeeze theorem or a suitable coordinate transformation.

Course material: Q06.5-Q06.6. Supplementary explanation: the method ladder, repeated-expression substitution and the family-of-parabolas argument.

6. Partial derivatives

The partial derivative with respect to $x$ at $(x_0,y_0)$ is

$\displaystyle f_x(x_0,y_0)=\lim_{\Delta x\to0}\frac{f(x_0+\Delta x,y_0)-f(x_0,y_0)}{\Delta x}.$

Only $x$ changes; $y$ remains fixed. Similarly,

$\displaystyle f_y(x_0,y_0)=\lim_{\Delta y\to0}\frac{f(x_0,y_0+\Delta y)-f(x_0,y_0)}{\Delta y}.$

6.1 Geometric meaning

Fixing $y=y_0$ cuts the surface $z=f(x,y)$ with a vertical plane parallel to the $xz$-plane. The slope of the resulting tangent line is $f_x$. Fixing $x=x_0$ gives a vertical slice parallel to the $yz$-plane whose tangent slope is $f_y$.

6.2 How to compute

Differentiate with respect to the named variable and treat every other independent variable as a constant.

Course example

If $f(x,y)=x^3y+y^2$, then

$\displaystyle f_x=3x^2y,\qquad f_y=x^3+2y.$

For $f_x$, $y$ behaves like a constant coefficient. For $f_y$, $x^3$ is a constant multiplying $y$.

6.3 Second and mixed partials

$\displaystyle f_{xx}=\frac{\partial^2f}{\partial x^2},\quad f_{xy}=\frac{\partial}{\partial y}(f_x),\quad f_{yx}=\frac{\partial}{\partial x}(f_y),\quad f_{yy}=\frac{\partial^2f}{\partial y^2}.$

Under standard conditions - for example, when the mixed partials are continuous near the point - Clairaut's theorem gives $f_{xy}=f_{yx}$. Do not state this equality without an appropriate regularity assumption.

7. Linear approximation and tangent planes

For small changes $\Delta x$ and $\Delta y$, a differentiable function satisfies

$\displaystyle \Delta f\approx f_x(x_0,y_0)\Delta x+f_y(x_0,y_0)\Delta y.$

If $z_0=f(x_0,y_0)$, the tangent plane to $z=f(x,y)$ at $(x_0,y_0,z_0)$ is

$\displaystyle z=z_0+f_x(x_0,y_0)(x-x_0)+f_y(x_0,y_0)(y-y_0).$

7.1 Procedure

  1. Compute $z_0=f(x_0,y_0)$.
  2. Find symbolic expressions for $f_x$ and $f_y$.
  3. Evaluate both partial derivatives at the base point.
  4. Insert them into the tangent-plane formula.
  5. For numerical approximation, identify $\Delta x=x-x_0$ and $\Delta y=y-y_0$.

Supplementary example: approximating a square root

Let $f(x,y)=\sqrt{x+y}$ near $(4,5)$. Then

$\displaystyle f(4,5)=3,\qquad f_x=f_y=\frac1{2\sqrt{x+y}},\qquad f_x(4,5)=f_y(4,5)=\frac16.$

Hence

$\displaystyle f(4+\Delta x,5+\Delta y)\approx3+\frac{\Delta x+\Delta y}{6}.$

This is a local approximation; retain the $\approx$ sign unless an error analysis proves equality.

Course material: PDF page 2, Lecture 9. Supplementary explanation: the worked approximation and step-by-step procedure.

8. Critical points and extrema

At an interior local maximum or minimum of a differentiable function,

$\displaystyle f_x(x_0,y_0)=0,\qquad f_y(x_0,y_0)=0.$

A point satisfying both equations is a critical point. This condition finds candidates only: a critical point can be a local minimum, local maximum or saddle point.

8.1 Second-derivative test

At a critical point, define

$\displaystyle A=f_{xx},\qquad B=f_{xy},\qquad C=f_{yy},\qquad D=AC-B^2,$

with all derivatives evaluated at that point.

ConditionConclusionLocal shape
$D>0$ and $A>0$Local minimumBowl opening upward
$D>0$ and $A<0$Local maximumBowl opening downward
$D<0$Saddle pointRises in some directions and falls in others
$D=0$InconclusiveUse another method or higher-order terms

Course example: completing the square

For

$\displaystyle f(x,y)=x^2-2xy+3y^2+2x-2y,$

solving $f_x=f_y=0$ gives the critical point $(-1,0)$. The lecture rewrites

$\displaystyle f=(x-y+1)^2+2y^2-1\ge-1.$

Equality occurs at $(-1,0)$, so this is a minimum. For quadratic functions, completing the square can be clearer and stronger than merely applying a classification table.

Local is not global

A global maximum or minimum may occur at an interior critical point, on the boundary of the domain, or through behaviour at infinity. The second-derivative test classifies local behaviour only.

8.2 Why the test works

Near a critical point, the first-order terms vanish, and the leading change is approximately quadratic:

$\displaystyle \Delta f\approx\frac A2(\Delta x)^2+B\Delta x\Delta y+\frac C2(\Delta y)^2.$

The sign pattern of this quadratic form determines whether nearby values lie above, below or on both sides of the critical value.

Course material: PDF pages 2-4, Lectures 9-10. Supplementary explanation: the method table, geometric descriptions and distinction between local and global extrema.

9. Least squares

Given data $(x_i,y_i)$, a line $y=ax+b$ usually does not pass through every point. Its residual at point $i$ is

$\displaystyle r_i=y_i-(ax_i+b).$

Least squares chooses $a$ and $b$ to minimise

$\displaystyle D(a,b)=\sum_{i=1}^n\big[y_i-(ax_i+b)\big]^2.$

The variables being optimised are $a$ and $b$, not the data coordinates. Setting $D_a=D_b=0$ gives the normal equations:

$\displaystyle \left(\sum x_i^2\right)a+\left(\sum x_i\right)b=\sum x_iy_i,$
$\displaystyle \left(\sum x_i\right)a+nb=\sum y_i.$

Why square the residuals?

Without squaring, positive and negative errors could cancel. Squaring makes every contribution nonnegative and penalises larger deviations more strongly.

Supplementary example

For $(0,1)$, $(1,3)$ and $(2,4)$:

$\displaystyle n=3,\quad\sum x_i=3,\quad\sum x_i^2=5,\quad\sum y_i=8,\quad\sum x_iy_i=11.$

The normal equations are $5a+3b=11$ and $3a+3b=8$, giving

$\displaystyle a=\frac32,\qquad b=\frac76.$

The least-squares line is therefore $y=\frac32x+\frac76$.

The lecture also notes two extensions:

  • For $y=ce^{ax}$ with $y>0$, take logarithms: $\ln y=ax+\ln c$.
  • For $y=ax^2+bx+c$, minimise the squared residuals in the three unknown coefficients, producing a $3\times3$ system.

Course material: PDF page 3, Lecture 9. Supplementary explanation: residual intuition and the numerical example. Log-linear fitting changes the error model because errors are measured after taking logarithms.

10. What to remember for the exam

  • Evaluation: substitute with brackets and check the domain before simplifying.
  • Domain: combine every restriction; a logarithm in a denominator creates two conditions.
  • Level sets: solve $f=k$ but preserve exclusions from the original domain.
  • Limits: continuity first, algebra second; different paths disprove, but matching paths do not prove.
  • Partial derivatives: vary one coordinate while freezing the others.
  • Tangent plane: evaluate $f$, $f_x$ and $f_y$ at the same base point.
  • Critical points: $f_x=f_y=0$ finds candidates; use $D=f_{xx}f_{yy}-f_{xy}^2$ to classify when $D\ne0$.
  • Global extrema: check boundaries and infinity, not only critical points.
  • Least squares: minimise squared residuals with respect to the model parameters.

Final verification habits

  • Test a proposed domain with one allowed point and one excluded boundary point.
  • Substitute representative points into level-set equations and the original function.
  • For a claimed non-existent limit, write the two paths and their distinct limiting values explicitly.
  • For a critical-point classification, state the critical point before evaluating $D$.
  • Label supplementary facts separately from statements directly contained in the lecture notes.
