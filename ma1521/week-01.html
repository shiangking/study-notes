MA1521 Calculus Guide: Limits, Differentiation, and Integration

Primary source: the four uploaded MIT OpenCourseWare 18.01 PDFs, Lectures 1-38. The notes cover more than one week, so this guide focuses on the areas requested: limits, differentiation, and integration techniques.

1. The central idea

Calculus has one recurring pattern:

  • Limits describe what happens as an input gets arbitrarily close to a value.
  • Differentiation uses a limit to measure instantaneous change.
  • Integration uses limits to measure accumulated change and is closely linked to differentiation by the Fundamental Theorem of Calculus.

The most important habit is to ask: What is changing? What is being accumulated? What assumptions make the operation valid?

2. Limits: the part to understand first

What a limit means

lim(x -> a) f(x) = L means that by choosing x sufficiently close to a (but not necessarily equal to a), f(x) can be made as close to L as desired.

The limit concerns nearby behaviour, not necessarily the value at a. For example, a function may have a hole at a but still have a limit there.

One-sided and two-sided limits

  • lim(x -> a-) f(x): approach from the left.
  • lim(x -> a+) f(x): approach from the right.
  • A two-sided limit exists only when both one-sided limits exist and are equal.

Example: if the left-hand behaviour approaches 2 but the right-hand behaviour approaches 5, then lim(x -> a) f(x) does not exist, even though both one-sided limits exist.

Direct substitution

If f is continuous at a, then

lim(x -> a) f(x) = f(a).

Polynomials, exponentials, sine, cosine, and rational functions are continuous wherever their formulas are defined. Direct substitution works for these cases.

Example:

lim(x -> 2) (x^2+3x-1) = 4+6-1 = 9.

The indeterminate form 0/0

0/0 is not a limit value. It means the expression needs further analysis.

Example:

lim(x -> 1) (x^2-1)/(x-1).

Factor first:

(x^2-1)/(x-1) = [(x-1)(x+1)]/(x-1) = x+1, for x != 1.

Therefore the limit is 2. The original function may be undefined at 1, but its nearby values approach 2.

Rationalising radicals

When a square root creates 0/0, multiply by the conjugate.

Example:

lim(x -> 0) [sqrt(1+x)-1]/x.

Multiply by [sqrt(1+x)+1]/[sqrt(1+x)+1]:

[sqrt(1+x)-1]/x = 1/[sqrt(1+x)+1].

The limit is 1/2.

Important trigonometric limits

These are fundamental in proving trig derivatives:

lim(x -> 0) sin(x)/x = 1.

lim(x -> 0) [1-cos(x)]/x = 0.

Angles must be measured in radians. The approximation sin x ≈ x near zero depends on radians.

Limits at infinity

For rational functions, compare the highest powers.

Example:

lim(x -> infinity) (3x^2-x+1)/(x^2+4) = 3.

Divide numerator and denominator by x^2; all lower-order terms vanish.

Continuity

f is continuous at a when:

  1. f(a) is defined;
  2. lim(x -> a) f(x) exists;
  3. the limit equals f(a).

For a continuous function, small changes in input produce small changes in output. Continuity is needed in several calculus theorems, including the Fundamental Theorem of Calculus and the Extreme Value Theorem.

L'Hopital's rule

For a genuine 0/0 or infinity/infinity form, and under the theorem's conditions,

lim f(x)/g(x) = lim f'(x)/g'(x).

Example:

lim(x -> 0) (e^x-1)/x = lim(x -> 0) e^x/1 = 1.

Do not use L'Hopital's rule before checking whether direct substitution or algebra is simpler.

A limit checklist

  1. Substitute directly.
  2. If the result is a normal number, stop.
  3. If it is 0/0, factor, cancel, rationalise, or use a known standard limit.
  4. If it is infinity/infinity, compare dominant terms or use L'Hopital's rule.
  5. Check one-sided behaviour when a denominator, absolute value, or piecewise definition is involved.

3. Differentiation: formulas and reasoning

Definition

f'(a) = lim(h -> 0) [f(a+h)-f(a)]/h.

The derivative is the instantaneous rate of change. It is also the slope of the tangent line.

Chain rule example

Differentiate y=sin(x^2+1).

The outer function is sine; the inner function is x^2+1:

dy/dx = cos(x^2+1) * 2x.

The common error is to omit 2x.

Product rule example

For y=x^2 e^x,

y' = 2x e^x + x^2 e^x = e^x(2x+x^2).

Logarithmic differentiation

For complicated products, quotients, or powers, take logarithms first.

Example: y=x^x for x>0.

ln y = x ln x.

Differentiate implicitly: y'/y = ln x+1.

Thus y'=x^x(ln x+1).

Implicit differentiation

If x and y satisfy an equation, differentiate both sides with respect to x, remembering that d(y)/dx=y'.

Example: x^2+y^2=25.

2x+2y y'=0, so y'=-x/y.

Higher derivatives and interpretation

  • f': slope or velocity.
  • f'': concavity or acceleration.
  • f''' and beyond: higher-order changes, useful in Taylor approximations and error analysis.

Linearisation

Near x=a,

f(x) ≈ f(a)+f'(a)(x-a).

Example: approximate sqrt(4.1) using f(x)=sqrt x and a=4.

f(4)=2, f'(4)=1/4, so

sqrt(4.1) ≈ 2+(1/4)(0.1)=2.025.

Applications

  • Increasing/decreasing: f'>0 means increasing; f'<0 means decreasing.
  • Local extrema: check critical points where f'=0 or undefined, plus endpoints.
  • Concavity: f''>0 means concave up; f''<0 means concave down.
  • Newton's method: x_(n+1)=x_n-f(x_n)/f'(x_n).
  • Mean Value Theorem: if continuous on [a,b] and differentiable on (a,b), some c satisfies f'(c)=[f(b)-f(a)]/(b-a).

Worked differentiation applications

Curve analysis

To analyse f(x), use this order:

  1. Find the domain and any intercepts or asymptotes.
  2. Solve f'(x)=0 and identify points where f' is undefined. These are critical points.
  3. Make a sign chart for f'. This tells you where the function increases or decreases.
  4. Use f'' to determine concavity and possible inflection points.
  5. Combine the information into a graph.

Example: Let f(x)=x^3-3x.

f'(x)=3x^2-3=3(x-1)(x+1), so the critical points are x=-1 and x=1.

  • f'>0 on (-infinity,-1) and (1,infinity): increasing.
  • f'<0 on (-1,1): decreasing.

Thus x=-1 is a local maximum and x=1 is a local minimum. Also,

f''(x)=6x, so the graph is concave down for x<0 and concave up for x>0. The concavity changes at x=0, giving an inflection point.

Optimisation

Suppose a rectangle has perimeter 20. If its sides are x and y, then

2x+2y=20, so y=10-x.

Its area is

A(x)=x(10-x)=10x-x^2, with 0<x<10.

Differentiate:

A'(x)=10-2x.

Set A'(x)=0: x=5. Since A''(x)=-2<0, this is a maximum. The maximum area is A(5)=25.

The important reasoning is that the constraint must first reduce the problem to one variable, and the domain and endpoints must be considered. A derivative equation alone does not prove a global maximum.

Related rates

If a circle has radius r and area A=pi r^2, then differentiating with respect to time gives

dA/dt=2pi r dr/dt.

If r=3 and dr/dt=2, then

dA/dt=2pi(3)(2)=12pi square units per unit time.

Differentiate first, then substitute the current values. Substituting before differentiating can destroy the relationship between the changing quantities.

4. Integration: the basic meaning

Indefinite integrals

An antiderivative F of f satisfies F'=f:

∫ f(x) dx = F(x)+C.

Key formulas:

  • ∫x^n dx = x^(n+1)/(n+1)+C, n != -1;
  • ∫1/x dx = ln|x|+C;
  • ∫e^x dx=e^x+C;
  • ∫cos x dx=sin x+C;
  • ∫sin x dx=-cos x+C;
  • ∫sec^2 x dx=tan x+C;
  • ∫1/(1+x^2) dx=arctan x+C.

Always differentiate your answer to check it.

Definite integrals

∫_a^b f(x)dx is the limit of sums of thin rectangles. It represents signed accumulation. The Fundamental Theorem says that if F'=f, then

∫_a^b f(x)dx=F(b)-F(a).

5. Integration techniques: how to choose

Technique 1: substitution

Use substitution when an expression contains an inner function and its derivative.

∫ f(g(x))g'(x)dx = ∫ f(u)du.

Example:

∫ 2x cos(x^2) dx.

Let u=x^2, so du=2x dx:

∫ cos u du=sin u+C=sin(x^2)+C.

For definite integrals, change the bounds: if u=g(x), replace x=a,b by u=g(a),g(b).

Technique 2: integration by parts

Use for products where one factor becomes simpler when differentiated:

∫u dv=uv-∫v du.

Example:

∫x e^x dx.

Take u=x, dv=e^x dx; then du=dx, v=e^x:

∫x e^x dx = x e^x - ∫e^x dx = e^x(x-1)+C.

Technique 3: trigonometric powers

For ∫sin^m x cos^n x dx:

  • If one exponent is odd, save one factor and convert the rest using sin^2x+cos^2x=1.
  • If both are even, use half-angle identities.

Example:

∫sin^3 x cos^2 x dx.

Save sin x, write sin^2x=1-cos^2x, and let u=cos x, du=-sin x dx:

∫(1-u^2)u^2(-du) = -u^3/3+u^5/5+C.

Technique 4: trigonometric substitution / identities

Use identities such as 1+tan^2x=sec^2x for powers of tangent and secant. For even powers, rewrite using sec^2x=1+tan^2x; for suitable odd powers of secant, save sec x tan x dx.

Technique 5: partial fractions

Use for rational functions P(x)/Q(x) after factoring Q.

Example:

∫1/(x^2-1) dx = ∫1/[(x-1)(x+1)] dx.

Decompose:

1/(x^2-1)=1/2[1/(x-1)-1/(x+1)].

Therefore

∫1/(x^2-1)dx = (1/2)ln|x-1|-(1/2)ln|x+1|+C.

Technique 6: inverse substitution

When an integral resembles a standard inverse-trigonometric derivative, rewrite it into that form:

  • ∫ dx/sqrt(1-x^2)=arcsin x+C;
  • ∫ dx/(1+x^2)=arctan x+C;
  • ∫ dx/(x sqrt(x^2-1))=arcsec|x|+C where defined.

Technique 7: reduction formulas

For repeated families such as ∫sin^n x dx or ∫x^n e^x dx, integration by parts produces a recurrence that reduces the exponent until a base case is reached. The key idea is systematic reuse, not memorising every individual formula.

6. Applications of integration: area and volume

The difficult part of an application is usually not evaluating the integral. It is deciding what a thin slice looks like, which variable to integrate with respect to, and what the correct bounds are.

6.1 Area under a graph

For a graph y=f(x) between x=a and x=b, the signed area is

A=∫_a^b f(x)dx.

If the graph is below the x-axis, this integral is negative. If the question asks for geometric area, split the interval at x-intercepts or use |f(x)| conceptually.

Example: Find the area between y=x^2, the x-axis, x=0, and x=2.

The curve is above the x-axis on [0,2], so

A=∫_0^2 x^2 dx=[x^3/3]_0^2=8/3.

If a graph crosses the axis, split it. For f(x)=x-1 from x=0 to x=2, the signed integral is zero, but the geometric area is

∫_0^1(1-x)dx + ∫_1^2(x-1)dx = 1/2+1/2=1.

6.2 Area bounded by the y-axis

The y-axis is x=0. If the region is described naturally by y=f(x) and has vertical boundaries, integrate with respect to x. The y-axis simply becomes one bound, often x=0.

Example: Find the area bounded by y=x^2, the x-axis, and the y-axis from x=0 to x=2.

The y-axis gives the left boundary x=0; the x-axis and curve meet at x=0, while the specified/right intersection is x=2. Therefore,

A=∫_0^2 x^2dx=8/3.

If the region is naturally described by horizontal slices, rewrite the curve as x=g(y) and integrate with respect to y.

6.3 Area between two curves

With vertical slices,

A=∫_a^b [top function - bottom function] dx.

The bounds a,b usually come from solving the intersection equation f(x)=g(x).

Example: Find the area between y=x and y=x^2.

Intersections satisfy x=x^2, so x=0,1. On [0,1], x is above x^2:

A=∫_0^1(x-x^2)dx=[x^2/2-x^3/3]_0^1=1/6.

With horizontal slices,

A=∫_c^d [right function - left function]dy.

Always sketch the region first. “Top minus bottom” applies only to vertical slices; “right minus left” applies to horizontal slices.

6.4 Volumes of revolution: the geometric decision

Rotating a planar region around an axis creates a solid. The method depends on the slice orientation:

  • Slices perpendicular to the axis produce disks or washers.
  • Slices parallel to the axis produce cylindrical shells.

The basic idea is always

volume ≈ cross-sectional area × thickness.

Then take a limit, producing an integral.

6.5 Disk method

Use disks when rotating a region around an axis creates solid circular cross-sections with no hole.

Rotating y=f(x) around the x-axis gives radius R=f(x). A thin disk has area pi R^2 and thickness dx:

V=∫_a^b pi[f(x)]^2dx.

Example: Rotate the region under y=x from x=0 to x=2 around the x-axis.

At position x, the radius is R=x. Hence

V=∫_0^2 pi x^2dx=pi[x^3/3]_0^2=8pi/3.

6.6 Washer method

Use washers when rotation creates a hole. If the outer radius is R and inner radius is r, the cross-sectional area is

pi R^2-pi r^2=pi(R^2-r^2).

Thus

V=∫_a^b pi[R(x)^2-r(x)^2]dx.

Example: Rotate the region between y=x and y=x^2 on [0,1] around the x-axis.

For 0<=x<=1, the outer radius is R=x and the inner radius is r=x^2. Therefore,

V=∫_0^1 pi[x^2-x^4]dx

=pi[x^3/3-x^5/5]_0^1=2pi/15.

The inner radius must be subtracted because the rotation leaves a cylindrical hole.

6.7 Rotation around the y-axis using shells

When vertical slices rotate around the y-axis, each slice creates a cylindrical shell.

  • Radius: distance from the y-axis, x.
  • Height: top minus bottom, f(x)-g(x).
  • Circumference: 2pi x.
  • Thickness: dx.

Therefore,

V=∫_a^b 2pi(radius)(height)dx

=∫_a^b 2pi x[f(x)-g(x)]dx.

Example: Rotate the region under y=x from x=0 to x=2 around the y-axis.

The shell radius is x, height is x, so

V=∫_0^2 2pi x(x)dx=2pi∫_0^2x^2dx=16pi/3.

6.8 Choosing between washers and shells

For rotation around the y-axis:

  • Vertical slices usually give shells using dx.
  • Horizontal slices usually give washers using dy.

Choose the method that avoids solving for the inverse function or splitting the region into multiple pieces. Both methods should give the same volume when set up correctly.

6.9 Work and average value

If force varies with position, a small amount of work is dW=F(x)dx, so

W=∫_a^bF(x)dx.

The average value of f on [a,b] is

f_avg=(1/(b-a))∫_a^bf(x)dx.

This follows because total accumulation equals average height times width.

6.10 A reliable area/volume setup checklist

  1. Sketch the curves and shade the region.
  2. Find intersections and identify the actual bounds.
  3. Decide whether slices are vertical or horizontal.
  4. For area, use top-minus-bottom or right-minus-left.
  5. For volume, identify radius, inner radius, outer radius, height, and thickness.
  6. Check that the integrand has the correct units: area for area problems and volume for volume problems.
  7. Estimate the answer's size before evaluating.

8. Most important misconceptions to correct

  1. 0/0 is not zero; it is an indeterminate form.
  2. A limit does not require the function to be defined at the target point.
  3. A critical point is only a candidate, not automatically an extremum.
  4. A definite integral is signed area, not always geometric area.
  5. The constant C belongs in indefinite integrals.
  6. Integration techniques are applications of the chain, product, and algebraic rules; they are not unrelated tricks.
