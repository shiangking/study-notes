Introduction and context

“For whereas in the past it was thought that every branch of mathematics depended on its own particular intuition which provided its concepts and prime truths, nowadays it is known to be possible, logically speaking, to derive practically the whole of known mathematics from a single source – the Theory of Sets.”

— Nicolas Bourbaki, Elements of Mathematics: Theory of Sets

The Bourbaki members pictured in the slides were Henri Cartan, André Weil, René de Possel, Charles Ehresmann, Laurent Schwartz, Jean Dieudonné, Claude Chevalley, Pierre Samuel, Jean-Pierre Serre, and Adrien Douady.

Set theory is important in computer science because it formalizes computation and the objects being computed. It is inseparable from logic, one of the foundations of computer science. Applications include data structures, database theory (relations over sets), formal-language theory, machine learning, and many other areas.

Motivating example: a Turing machine

Following Michael Sipser, a Turing machine is a 7-tuple

(Q, Σ, Γ, δ, q₀, q_accept, q_reject),

where Q, Σ, and Γ are finite sets and:

  • Q is the set of states.
  • Σ is the input alphabet and does not contain the special blank symbol ⊔.
  • Γ is the tape alphabet, where ⊔ ∈ Γ and Σ ⊆ Γ.
  • δ: Q × Γ → Q × Γ × {L,R} is the transition function.
  • q₀ ∈ Q is the start state.
  • q_accept ∈ Q is the accept state.
  • q_reject ∈ Q is the reject state, with q_reject ≠ q_accept.
Supplementary explanation: set theory appears in nearly every component: states and alphabets are sets, configurations are tuples, the transition rule is a function between Cartesian products, and inclusion Σ ⊆ Γ relates the two alphabets.

5.1 Definitions

5.1.1 Sets and notation

A set is an unordered collection of objects. The contained objects are its elements or members. Examples include S = {3,a,√5} and the set of the seven days of the week.

Set-roster notation

Roster notation lists elements inside braces: {1,2,3}, {1,2,3,…,100}, or {1,2,3,…}. The ellipsis … means “and so forth” and should only be used when the pattern is unambiguous.

Order and repetition do not matter:

{9,8,7} = {7,9,8} = {7,8,7,9,9,7,7}.

A multiset records multiplicity, so {a,b,c} and {a,b,b,c} would differ as multisets. Multisets are outside this lecture.

Membership and cardinality

  • x ∈ S: x is an element of S.
  • x ∉ S: x is not an element of S.
  • |S|: the cardinality or number of distinct elements of S.

Examples: b ∈ {a,b,c}, 456 ∈ {1,2,…,999}, f ∉ {a,b,c}, and |{a,b,c}| = 3.

The bars |·| may instead mean absolute value, depending on context. Other texts may use n(S) or #S; CS1231S uses |S|.

Supplementary worked answers — membership and cardinality
  1. {a} ∈ {a,{a,b},c} is false. The set contains a, {a,b}, and c, not the singleton {a}.
  2. |{1,{1,2},{3,{4,5},6},{2,3}}| = 4. Each nested set counts as one element.
  3. If Uₙ={n,−n}, then |U₁|=2, |U₋₅|=2, and |U₀|=1, since −0=0 and duplicates collapse.

Notation such as ℚ⁺, ℚ⁻, ℚ≥m, ℝ⁺, ℝ⁻, and ℝ≥m is interpreted similarly. Zero is neither positive nor negative.

Set-builder notation

Given a universe U and predicate P(x),

{x ∈ U : P(x)} or {x ∈ U | P(x)}

is the set of all x in U satisfying P(x). For example, {x ∈ ℤ≥0 : Even(x)} is the set of non-negative even integers.

For S={x∈U:P(x)}, an object z belongs to S exactly when both z∈U and P(z) hold. If z is outside U or P(z) is false, then z∉S.

Supplementary worked answers — set-builder notation
  • {x∈ℝ:−2<x<5} = (−2,5).
  • {x∈ℤ:−2<x<5} = {−1,0,1,2,3,4}.
  • {x∈ℤ⁺:−2<x<5} = {1,2,3,4}.
The same inequality produces different sets because the domains differ.

Replacement notation

Given a set A and term t(x),

{t(x) : x ∈ A} or {t(x) | x ∈ A}

contains every output of t as x ranges through A. For example, {x+1:x∈ℤ≥0}=ℤ⁺; in particular, 1=0+1 belongs but 0 does not.

To show z ∈ {t(x):x∈A}, find a witness x∈A for which t(x)=z. If no such witness exists, z is not a member.

Supplementary explanation: set-builder notation filters a domain using a predicate; replacement notation maps a domain through an expression. Thus {x∈ℤ:x²<5} filters integers, while {x²:x∈ℤ} collects square outputs. Replacement outputs may repeat, but repeated values still occur only once in the resulting set.

5.1.2 Subsets, proper subsets, empty set, and singleton

A ⊆ B iff every element of A is also an element of B:

A ⊆ B ⇔ ∀x(x∈A → x∈B).

We may also write B ⊇ A and say B contains, includes, or is a superset of A. Avoid ⊂, which has conflicting meanings across textbooks.

A is a proper subset of B, written A ⊊ B, iff A⊆B and A≠B. Inclusion is then strict.

A is not a subset of B iff A has a counterexample element:

A ⊈ B ⇔ ∃x(x∈A ∧ x∉B).

The empty set, ∅ or {}, has no elements. It is a subset of every set (Theorem 6.2.4) because ∀x(x∈∅→x∈A) is vacuously true. A singleton has exactly one element.

5.1.3 Ordered pairs

An ordered pair has form (x,y). Order matters:

(a,b)=(c,d) ⇔ (a=c) ∧ (b=d).

Supplementary worked answers: (1,2)≠(2,1). However, (3,0.5)=(√9,1/2) because the positive square root √9=3 and 1/2=0.5.

5.1.4 Cartesian products

For sets A and B,

A×B = {(a,b):a∈A ∧ b∈B}.

In general, A×B≠B×A because ordered pairs remember position. If A and B are finite, |A×B|=|A||B|.

Supplementary worked answers: Let A={1,2,3} and B={u,v}.
  • A×B={(1,u),(1,v),(2,u),(2,v),(3,u),(3,v)}, so |A×B|=6.
  • B×A={(u,1),(u,2),(u,3),(v,1),(v,2),(v,3)}, so |B×A|=6.
  • B×B={(u,u),(u,v),(v,u),(v,v)}, so |B×B|=4.

ℝ×ℝ is the set of ordered pairs of real numbers. Each (x,y) is a unique point in the Cartesian plane, with x the horizontal and y the vertical coordinate—for example, (2,1), (−3,2), (−2,−2), and (1,−2).

5.1.5 Set equality

Sets are equal exactly when they contain the same elements:

A=B ⇔ (A⊆B ∧ B⊆A) ⇔ ∀x(x∈A ↔ x∈B).

To prove X=Y by double inclusion:

  1. Prove X⊆Y.
  2. Prove Y⊆X (equivalently, X⊇Y).
  3. Conclude X=Y.
Supplementary worked answers:
  • {1,2,3}, {3,1,2}, and {1,1,2,3,3,3} are the same set: order and repetition do not matter.
  • {9}≠9: the left side is a singleton set, while the right side is a number.
  • {9}≠{{9}}: their sole elements are 9 and {9}, respectively.
  • {9}≠{9,∅}: the right side has the additional element ∅.

Worked proof: {x∈ℤ:x²=1}={1,−1}

Let X={x∈ℤ:x²=1} and Y={1,−1}.

  • X⊆Y: let x∈X. Then x²=1, so x²−1=(x−1)(x+1)=0. Hence x=1 or x=−1, giving x∈Y.
  • Y⊆X: if x∈Y, then x is 1 or −1. In either case x²=1, so x∈X.

Therefore X=Y. ∎

5.1.6 Venn diagrams

John Venn introduced these diagrams in 1881. Sets are drawn as planar regions. If A⊆B, region A lies entirely inside B (or coincides with it). If A⊈B, at least some portion of A lies outside B; A may be disjoint from B, overlap B, or contain B while extending beyond it.

Supplementary exam note: a Venn diagram is useful for intuition and finding candidate identities, but unless diagrams are expressly permitted as proofs, prove the result elementwise or with established set identities.

Indexed unions and intersections

For sets A₀,A₁,A₂,…⊆U:

  • ⋃ᵢ₌₀ⁿ Aᵢ=A₀∪A₁∪⋯∪Aₙ={x∈U:x∈Aᵢ for at least one i∈{0,…,n}}.
  • ⋃ᵢ₌₀^∞ Aᵢ={x∈U:x∈Aᵢ for at least one non-negative integer i}.
  • ⋂ᵢ₌₀ⁿ Aᵢ=A₀∩A₁∩⋯∩Aₙ={x∈U:x∈Aᵢ for every i∈{0,…,n}}.
  • ⋂ᵢ₌₀^∞ Aᵢ={x∈U:x∈Aᵢ for every non-negative integer i}.
Supplementary explanation: indexed union behaves like an existential quantifier (“in at least one”), while indexed intersection behaves like a universal quantifier (“in all”).

5.1.8 Partitions

A and B are disjoint iff A∩B=∅. A family A₁,A₂,… is mutually or pairwise disjoint iff Aᵢ∩Aⱼ=∅ whenever i≠j.

A collection {A₁,…,Aₖ} is a partition of A iff:

  1. every block Aᵢ is a non-empty subset of A;
  2. the blocks are pairwise disjoint; and
  3. A=A₁∪⋯∪Aₖ.

The supporting Quotient–Remainder Theorem (Theorem 4.4.1) says that for every integer n and positive integer d, there exist unique integers q and r such that n=dq+r and 0≤r<d.

Supplementary worked answers — partitions
  1. {{1,2},{3,4},{5,6}} is a partition of {1,2,3,4,5,6}: each block is non-empty, the blocks are pairwise disjoint, and their union is the whole set.
  2. {T₀,T₁,T₂}, where Tᵣ={n∈ℤ:n=3k+r for some k∈ℤ}, is a partition of ℤ. By quotient–remainder with d=3, every integer has exactly one remainder 0, 1, or 2. Existence gives coverage; uniqueness makes the classes pairwise disjoint. Each class is non-empty—for example, 0, 1, and 2 are witnesses.

5.1.9 Power sets

The power set 𝒫(A) is the set of all subsets of A. If A={x,y}, then

𝒫(A)={∅,{x},{y},{x,y}}.

If A is finite with |A|=n, then |𝒫(A)|=2ⁿ. The formal proof by mathematical induction appears in Lecture 8.

Supplementary explanation: each of the n elements independently has two choices—either included or excluded—giving 2×⋯×2=2ⁿ possible subsets. Also remember that ∅∈𝒫(A) and A∈𝒫(A) for every A.

5.1.10 Ordered n-tuples and products

For positive integer n, an ordered n-tuple has form (x₁,x₂,…,xₙ); entries need not be distinct. A 2-tuple is an ordered pair and a 3-tuple is an ordered triple.

Two n-tuples are equal iff corresponding components are equal:

(x₁,…,xₙ)=(y₁,…,yₙ) ⇔ x₁=y₁ ∧ ⋯ ∧ xₙ=yₙ.

A₁×⋯×Aₙ={(a₁,…,aₙ):a₁∈A₁ ∧ ⋯ ∧ aₙ∈Aₙ}. The power Aⁿ means the n-fold product A×⋯×A.

Supplementary worked answers: Let A₁={x,y}, A₂={1,2,3}, and A₃={a,b}.
  • A₁×A₂={(x,1),(x,2),(x,3),(y,1),(y,2),(y,3)}.
  • (A₁×A₂)×A₃ has elements ((x,1),a), ((x,1),b), …, ((y,3),a), ((y,3),b).
  • A₁×A₂×A₃ has elements (x,1,a), (x,1,b), …, (y,3,a), (y,3,b).
Both latter sets have 2·3·2=12 elements, but they are not literally equal: one contains nested ordered pairs and the other contains ordered triples.

5.2 Properties of sets

5.2.1 Subset relations and procedural definitions

Theorem 6.2.1 gives, for all sets A and B:

  • A∩B⊆A and A∩B⊆B.
  • A⊆A∪B and B⊆A∪B.

Subset inclusion is transitive: A⊆B ∧ B⊆C → A⊆C.

For X,Y⊆U and a,b∈U, procedural forms turn membership into logic:

Membership statementEquivalent condition
a∈X∪Ya∈X ∨ a∈Y
a∈X∩Ya∈X ∧ a∈Y
a∈X\Ya∈X ∧ a∉Y
a∈Xᶜa∉X
(a,b)∈X×Ya∈X ∧ b∈Y

Here Xᶜ=U\X; complements always depend on the chosen universal set.

  • Complements of bounds: Uᶜ=∅ and ∅ᶜ=U.

Set theory and propositional logic

Set identities and logical equivalences share the structure of Boolean algebra. Fix an arbitrary element x and read “x∈A” as proposition p:

LogicSets
p∨qA∪B
p∧qA∩B
¬pAᶜ
trueU
false∅

Under this correspondence, the commutative, associative, distributive, identity, complement/negation, double complement/negation, idempotent, universal-bound, De Morgan, and absorption laws match term for term. Likewise, ¬true≡false corresponds to Uᶜ=∅, while ¬false≡true corresponds to ∅ᶜ=U.

Supplementary explanation: this is why an elementwise proof of a set identity often becomes a propositional-logic calculation. Set equality is obtained once every x has equivalent membership conditions on both sides.

5.2.3 Examples of proofs involving sets

Example 1: De Morgan's law

Prove (A∪B)ᶜ=Aᶜ∩Bᶜ in universal set U.

Let x be an arbitrary element of U. Then:

x∈(A∪B)ᶜ
⇔ x∉A∪B (definition of complement)
⇔ ¬(x∈A ∨ x∈B) (definition of union)
⇔ (x∉A ∧ x∉B) (De Morgan's law for propositions)
⇔ (x∈Aᶜ ∧ x∈Bᶜ) (definition of complement)
⇔ x∈Aᶜ∩Bᶜ (definition of intersection).

Thus every x belongs to the left side iff it belongs to the right side, so (A∪B)ᶜ=Aᶜ∩Bᶜ. ∎

Example 2: intersection plus difference

Using set identities, prove (A∩B)∪(A\B)=A.

(A∩B)∪(A\B)
=(A∩B)∪(A∩Bᶜ) (set-difference law)
=A∩(B∪Bᶜ) (distributive law)
=A∩U (complement law)
=A (identity law). ∎

Lecture 05 exam checklist

  1. Distinguish x∈A from {x}⊆A; one relates an object to a set, the other compares two sets.
  2. Order and duplicates do not matter in sets, but order does matter in tuples.
  3. To disprove A⊆B, find one x with x∈A and x∉B.
  4. To prove set equality, use double inclusion or prove equivalent membership conditions for arbitrary x.
  5. Complement depends on U; always identify the universal set.
  6. Indexed union means “at least one index”; indexed intersection means “every index”.
  7. A partition requires non-empty blocks, pairwise disjointness, and complete coverage.
  8. A finite n-element set has 2ⁿ subsets.
  9. Translate ∪,∩,ᶜ,U,∅ to ∨,∧,¬,true,false when proving identities.
