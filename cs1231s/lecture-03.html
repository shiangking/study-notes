Predicate Logic

Predicate logic extends propositional logic by introducing variables, domains, and quantifiers. It lets us express statements such as “every integer has a successor” and “some integer is prime”.

3.1 Predicates and quantified statements I

3.1.1 Propositions, predicates, domains, and truth sets

  • A proposition has a fixed truth value and contains no free variable. Example: 2 + 3 = 5.
  • A predicate is a sentence with finitely many variables that becomes a statement when values are substituted. Examples: x + 3 = 5 and n < 2.
  • The domain (universe of discourse/universal set) is the set of allowed substitutions.

If P(x) is a predicate over domain D, its truth set is

{x ∈ D | P(x)}.

Example: if D = ℤ and P(x) is x² = 4, the truth set is {−2, 2}. If D = ℕ, the answer depends on whether the course defines ℕ to include 0, but in either convention the truth set here is {2}. Domains matter.

3.1.2 Universal quantifier ∀

∀x ∈ D, Q(x) means “for all/any/every/each x in D, Q(x)”. It is true iff Q(x) holds for every member of D and false if there is at least one counterexample.

Example: ∀n ∈ ℤ, n² ≥ 0 is true. ∀n ∈ ℤ, n² > 0 is false because n = 0 is a counterexample.

For a finite D, the method of exhaustion checks every element.

3.1.3 Existential quantifiers ∃ and ∃!

∃x ∈ D such that Q(x) means “there is at least one x in D for which Q(x)”. It is true if one witness exists and false only if Q(x) fails for every x in D.

∃!x ∈ D, Q(x) means “there exists exactly one”. This makes two claims: existence and uniqueness.

  • ∃n ∈ ℤ, n² = 9 is true; 3 is one witness (−3 is another).
  • ∃!n ∈ ℤ, n² = 9 is false because there are two witnesses.
  • ∃!n ∈ ℤ, n + 4 = 0 is true; the unique witness is −4.

3.1.5–3.1.7 Universal conditionals and domain narrowing

A universal conditional has form ∀x (P(x) → Q(x)). It says every object satisfying P also satisfies Q.

When D = {x ∈ U | P(x)}, the following are equivalent:

  • ∀x ∈ U (P(x) → Q(x)) ≡ ∀x ∈ D, Q(x).
  • ∃x ∈ U (P(x) ∧ Q(x)) ≡ ∃x ∈ D, Q(x).

Notice the different connective: restricting a universal statement uses implication; restricting an existential statement uses conjunction.

Example: “Every even integer has an even square” may be written as ∀n ∈ ℤ (Even(n) → Even(n²)), or as ∀n ∈ {even integers}, Even(n²).

Mathematics often uses implicit quantification. “If x > 2, then x² > 4” normally means ∀x ∈ ℝ (x > 2 → x² > 4).

3.1.8 Tarski's World

Tarski's World, created by Jon Barwise and John Etchemendy for The Language of First-Order Logic, evaluates quantified statements in a grid world of geometric blocks. Objects may be triangles, squares, or circles and may be blue, gray, or black.

Typical predicates include Triangle(x), Square(x), Circle(x), Blue(x), Gray(x), Black(x), RightOf(x,y), Above(x,y), SameColorAs(x,y), and x = y.

Translation example: “Every blue triangle is above some square” becomes ∀x ((Blue(x) ∧ Triangle(x)) → ∃y (Square(y) ∧ Above(x,y))).

3.2 Predicates and quantified statements II

3.2.1–3.2.3 Negating quantified statements

Push a negation through a quantifier by swapping the quantifier and negating the predicate:

Original negationEquivalent formEnglish
¬(∀x ∈ D, P(x))∃x ∈ D, ¬P(x)“Not all” means “at least one is not”.
¬(∃x ∈ D, P(x))∀x ∈ D, ¬P(x)“There is none” means “every one fails”.

For universal conditionals:

¬∀x(P(x) → Q(x)) ≡ ∃x ¬(P(x) → Q(x)) ≡ ∃x(P(x) ∧ ¬Q(x)).

Example: the negation of “Every CS1231S student submitted the tutorial” is “At least one CS1231S student did not submit the tutorial.” It is not “No CS1231S student submitted”.

Over a finite domain D = {x₁,…,xₙ}:

  • ∀x ∈ D, Q(x) ≡ Q(x₁) ∧ … ∧ Q(xₙ).
  • ∃x ∈ D, Q(x) ≡ Q(x₁) ∨ … ∨ Q(xₙ).

This explains why quantifier negation generalizes De Morgan's laws.

3.2.4 Vacuous truth

∀x ∈ D (P(x) → Q(x)) is vacuously true if P(x) is false for every x in D. There are no P-objects that can violate Q.

Likewise, ∀a ∈ X, P(a) is vacuously true when X = ∅. This is why the empty set is a subset of every set B:

∅ ⊆ B ≡ ∀x (x ∈ ∅ → x ∈ B), and x ∈ ∅ is always false.

Common trap: a universal claim over an empty collection is true, but an existential claim over it is false. There is no counterexample to the universal statement and no witness for the existential statement.

3.2.5–3.2.6 Variants, necessity, and sufficiency

For ∀x ∈ D (P(x) → Q(x)):

VariantFormRelationship
Contrapositive∀x ∈ D (¬Q(x) → ¬P(x))Logically equivalent
Converse∀x ∈ D (Q(x) → P(x))Not generally equivalent
Inverse∀x ∈ D (¬P(x) → ¬Q(x))Not generally equivalent

For predicates r(x) and s(x):

  • r is sufficient for s: ∀x(r(x) → s(x)).
  • r is necessary for s: ∀x(s(x) → r(x)), equivalently ∀x(¬r(x) → ¬s(x)).
  • “r only if s”: ∀x(r(x) → s(x)).

3.3 Statements with multiple quantifiers

3.3.1–3.3.5 Order and interpretation

∀x ∈ D, ∃y ∈ E, P(x,y) means: after an x is given, a suitable y can be chosen. The selected y may depend on x.

∃y ∈ E, ∀x ∈ D, P(x,y) means: one fixed y works for every x.

Example over ℤ:

  • ∀x ∃y (y > x) is true: choose y = x + 1.
  • ∃y ∀x (y > x) is false: this would assert a greatest integer.

Thus alternating quantifiers generally cannot be exchanged:

∀x∃y P(x,y) ≢ ∃y∀x P(x,y).

Adjacent quantifiers of the same kind can be swapped:

  • ∀x∀y P(x,y) ≡ ∀y∀x P(x,y) ≡ ∀x,y P(x,y).
  • ∃x∃y P(x,y) ≡ ∃y∃x P(x,y) ≡ ∃x,y P(x,y).

Dependency viewpoint: in ∀x∃y, y is allowed to be a function of x. In ∃y∀x, y must be selected before x and cannot adapt.

3.3.4 Negating multiple quantifiers

Move the negation inward one quantifier at a time, swapping each:

  • ¬(∀x ∈ D, ∃y ∈ E, P(x,y)) ≡ ∃x ∈ D, ∀y ∈ E, ¬P(x,y).
  • ¬(∃x ∈ D, ∀y ∈ E, P(x,y)) ≡ ∀x ∈ D, ∃y ∈ E, ¬P(x,y).

English example: negate “Every student likes some tutorial question.” The result is “There is a student who likes no tutorial question,” not “Every student dislikes every question.”

3.3.6 Purely formal notation

If quantifiers range over one universe and domain restrictions must be written inside the predicate:

  • ∀x ∈ D, P(x) becomes ∀x(x ∈ D → P(x)).
  • ∃x ∈ D, P(x) becomes ∃x(x ∈ D ∧ P(x)).

The implication/conjunction distinction is essential. Using ∃x(x ∈ D → P(x)) could be satisfied merely by choosing an x outside D.

3.4 Arguments with quantified statements

3.4.1–3.4.4 Instantiation and universal syllogisms

Universal instantiation: if P is true of every member of D, then P is true of any particular a in D.

RuleForm
Universal modus ponens∀x(P(x) → Q(x)), P(a) ⊢ Q(a)
Universal modus tollens∀x(P(x) → Q(x)), ¬Q(a) ⊢ ¬P(a)

Example: every multiple of 4 is even. Since 20 is a multiple of 4, 20 is even (universal modus ponens). Since 15 is not even, 15 is not a multiple of 4 (universal modus tollens).

3.4.6–3.4.7 Diagrams and further forms

Euler/Venn diagrams represent predicates as regions. An argument is valid only if every possible diagram satisfying the premises also forces the conclusion. One compatible diagram where the conclusion fails disproves validity.

Universal transitivity:

∀x(P(x) → Q(x)), ∀x(Q(x) → R(x)) ⊢ ∀x(P(x) → R(x)).

Diagrammatically, if region P is inside Q and Q is inside R, then P is inside R.

Quantified fallacies:

  • Converse error: ∀x(P(x) → Q(x)), Q(a) ⊢ P(a) is invalid.
  • Inverse error: ∀x(P(x) → Q(x)), ¬P(a) ⊢ ¬Q(a) is invalid.

3.4.8 Rules of inference for quantified statements

NameRuleRestriction to remember
Universal instantiation∀x ∈ D, P(x) ⊢ P(a)a must belong to D.
Universal generalizationP(a) for arbitrary a in D ⊢ ∀x ∈ D, P(x)a must be arbitrary, not a convenient special case.
Existential instantiation∃x ∈ D, P(x) ⊢ P(a) for some aa denotes an unspecified witness; do not assume extra properties.
Existential generalizationP(a) for some a in D ⊢ ∃x ∈ D, P(x)Confirm a is in D.
Classic generalization mistake: proving P(2) does not prove ∀x P(x). Universal generalization requires a proof for an arbitrary member, with no special assumptions beyond domain membership.

3.4.9 Abduction

Suppose we know ∀x(P(x) → Q(x)) and observe Q(a). Inferring P(a) would be the invalid converse error if claimed as a deduction. In medicine, AI, and everyday reasoning, treating P(a) as a plausible explanation is called abduction.

Example: influenza can cause fever; the patient has a fever; influenza is a possible diagnosis. This is useful hypothesis generation, not deductive certainty, because many conditions cause fever.

Lecture 03 exam checklist

  1. Always identify the domain before judging truth.
  2. To negate quantifiers, swap ∀ ↔ ∃ and negate the predicate.
  3. Negating a conditional produces P ∧ ¬Q.
  4. Do not exchange alternating quantifiers.
  5. Restricted universal uses →; restricted existential uses ∧.
  6. A universal proof needs an arbitrary object; an existential proof needs one witness.
